# POO Programación

Prácticas de **Programación Orientada a Objetos en Java** (DAW): herencia, interfaces, clases abstractas y modelado de problemas.

## Contenido

Cada práctica está en su propio paquete de `src/main/java/org/example/`:

| Paquete | Qué trabaja |
| --- | --- |
| `Practica1` | Programas y empleados, con diagrama UML (`Practica1.puml`) |
| `Pokedex` | Herencia e interfaces con tipos de Pokémon |
| `Pactica3` | Instituto, cursos y estudiantes |
| `ED` | Libros y usuarios |
| `PreExamen_POO` | Cuentas y clientes |

## Requisitos y ejecución

- JDK 25 y Maven (o IntelliJ IDEA).
- `mvn compile`
